# Reglas del Proyecto

## Convenciones de Git Commits
- Siempre que realices un commit de Git en este repositorio, debes utilizar obligatoriamente las pautas de la skill `commit-detallado` definidas en [.agents/skills/commit-detallado/SKILL.md](file:///.agents/skills/commit-detallado/SKILL.md).
- Todos los mensajes de commit deben redactarse enteramente en **español** siguiendo el estándar de **Conventional Commits**: `<tipo>(<alcance>): <descripción corta en minúsculas y sin punto final>`.
- Para cambios importantes o que modifiquen múltiples archivos, incluye siempre un **cuerpo de commit** detallado explicando el "por qué" y el contexto técnico de los cambios, limitando las líneas a 72 caracteres.
